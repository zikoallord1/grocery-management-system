# نظام إدارة البقالات

نظام تجاري مستقل لإدارة البقالات والعمل دون الحاجة إلى اتصال بالإنترنت.

## الهدف

بناء برنامج احترافي وسهل الاستخدام لإدارة:
- المبيعات
- المشتريات
- المخزون
- العملاء والديون
- الموردين
- المصروفات
- الصندوق
- الأرباح والخسائر
- التقارير
- الباركود
- المستخدمين والصلاحيات
- النسخ الاحتياطي والاستعادة
- الترخيص والتثبيت

## مبدأ أساسي

تسجيل العملية التجارية مرة واحدة ثم يقوم النظام تلقائيا بتحديث البيانات المرتبطة بها دون تكرار الإدخال.

## الحالة الحالية

مرحلة التخطيط والتصميم قبل البرمجة.
