# استراتيجية بيانات الاختبار  نظام إدارة البقالات V1.0

## الهدف

توفير بيانات تجريبية آمنة ومتكررة وقابلة لإعادة الإنشاء أثناء التطوير والاختبار.

## القواعد

- لا تستخدم بيانات عملاء حقيقيين.
- لا تحفظ كلمات مرور حقيقية.
- لا ترفع قواعد بيانات الاختبار إلى Git.
- البيانات التجريبية يجب أن تكون واضحة.
- Seed Script يجب أن يكون Idempotent قدر الإمكان.
- لا يعاد إدخال نفس البيانات عند إعادة التشغيل.

بيانات الاختبار لا يجوز أن تؤثر على بيانات حقيقية.
